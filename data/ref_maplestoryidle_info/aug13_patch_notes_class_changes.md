# August 13 patch notes — class changes (transcribed from ~/Downloads/August 13 Patch Notes - class changes.pdf)

Source: https://forum.nexon.com/maplestoryidle/board_view?board=6675&thread=3522342 (printed 9/7/26).
Official Nexon text; authoritative for WHAT CHANGED. Note: patch notes use Nexon's own English skill
names, which sometimes differ from the wiki's (e.g. patch "Focused Fury" = wiki "Concentration",
patch "Speed Mirage" = wiki "Flash Mirage", patch "Reckless Hunt: Bow" = site/wiki "Extreme Archery: Bow",
patch "Gust Charm"/"Assassin's Mark" = site "Gust Charm"/"Mark of Assassin").

Also in the same patch: Candle artifact equip effect duration 30s -> 40s.

## Hero
- Puncture: Targets 5 -> 10; Cooldown 19s -> 17s; Damage Taken Increase +10% effect from wound expanded from boss -> applies to all targets; hit effects trigger faster when attack speed is high.
- Enhanced Raging Blow: Targets 9 -> 12; Damage 550% -> 610%; Cooldown 19s -> 17s.
- Enrage: Effect Duration 5s -> 7s; Activation Interval 10s -> 12s; added an effect that additionally activates at the start of combat.
- Magic Crash: Targets 5 -> 9; Effect Range +50%.

## Paladin
- Divine Shield: added an effect that additionally activates at the start of combat.
- Magic Crash: Targets 5 -> 9; Effect Range +50%.

## Dark Knight
- Evil Eye: improved to move while staying fully attached to the character.
- Evil Eye Shock: Effect Range +17%.
- Lord of Darkness: Duration 5s -> 8s; Critical Rate 8% -> 10%; Critical Damage 30% -> 40%; Cooldown 2s -> 3s.
- Dark Resonance: added an effect that increases damage to boss monsters by 20%; Cooldown 35s -> 32s.
- Magic Crash: Targets 5 -> 9; Effect Range +50%.

## Arch Mage (Ice/Lightning)
- Freezing Crush: Frost can now also be applied with basic attacks; Frost Infliction Chance 25% -> 40%; Decreased Speed per Frost stack 5% -> 6% (no longer increases with skill level); Decreased Evasion per Frost stack 1 -> 2.
- [Mastery] MP Eater - MP Boost (Lv. 49): Trigger Condition MP 50% or above -> MP 35% or above.
- [Mastery] Freezing Crush - Aura (Lv. 54): Frost Infliction Interval 2s -> 3s; Targets 5 -> 8.
- Shatter: added an effect that reduces damage taken by 5%.
- Thunder Spear: Targets 6 -> 8.
- Elemental Decrease: Trigger Chance 20% -> 25%; Damage Taken Increase 10% -> 12%.
- Element Amplification: Trigger Condition MP 50% or above -> MP 35% or above.
- Chain Lightning: improved so chain effect finds more appropriate targets.
- Freezing Breath: Cooldown 45s -> 40s.
- Blizzard: Targets 5 -> 7.
- Frozen Orb: Frozen Orb Duration 5s -> 6s; decreased Orb Speed.
- [Mastery] Blizzard - Final Attack (Lv. 113): Additional Damage 750% -> 950%; Trigger Chance 20% -> 30%; Cooldown set to 1s.
- Frost Clutch: Damage Increase per Frost stack 6% -> 4%; effect now applies to all Ice/Lightning skills (previously Lightning skills only).

## Arch Mage (Fire/Poison)
- [Mastery] MP Eater - MP Boost (Lv. 49): Trigger condition MP 50% or above -> MP 35% or above.
- Burning Magic: added an effect that reduces damage taken by 5%.
- Elemental Decrease: Trigger chance 20% -> 25%; Damage Taken increase 10% -> 12%.
- Element Amplification: Trigger condition MP 50% or above -> MP 35% or above.
- Poison Mist: added a limit so that only 1 poisonous fog can be active at a time.
- Mist Eruption: number of explosions that can be triggered per poisonous fog 1 -> 2; cooldown until next explosion after each explosion: 4s.
- Meteor Shower: Targets 5 -> 7.
- Flame Haze: skill structure changed. Before: a flame orb explodes 1.5s later, dealing damage and inflicting Burn on up to 10 enemies near the orb. After: inflicts Burn on all enemies touched by the orb, then 2s later, up to 10 enemies in the area the orb passed through take explosion damage. Burn damage interval 1s -> 0.5s; Burn duration on boss targets 30s -> 20s.
- [Mastery] Mist Eruption - Explosion (Lv. 108): Before: Max explosions +1 (Cooldown 2s). After: Max explosions +1, explosion cooldown -1s.
- [Mastery] Meteor Shower - Final Attack (Lv. 113): Additional damage 750% -> 950%; Trigger chance 20% -> 30%; Cooldown set to 1s.
- [Mastery] Flame Haze - Poison Mist (Lv. 118): Added effect: Poison Mist max count +1.
- Fervid Drain: Damage increase per Poison stack 6% -> 4%; effect now applies to all Fire/Poison skills (previously Fire skills only).
